## Design Context

### Users
Non-technical professionals (designers, social media managers, PR, content creators, IR) onboarding to work with the Sky Ecosystem. They arrive at this course to understand the dual-brand system (sky.money retail vs Sky Ecosystem institutional), protocol mechanics, governance, and production standards. They need clarity without technical overwhelm — a professional, trustworthy learning environment that matches the institutional quality of Sky itself.

### Brand Personality
**Three words**: Institutional, Precise, Modern

**Voice & Tone**:
- Professional and authoritative — this is a serious financial ecosystem
- Clean and direct — no decorative flourishes, no unnecessary warmth
- Institutional-grade — the UI should feel like it belongs to the same organization as Skyeco.com
- Confident but not flashy — Web3-native without the hype

**Emotional Goals**:
- **Trust through polish**: The interface must feel as premium as the Sky brand
- **Clarity over charm**: Information hierarchy is paramount; readability is the priority
- **Institutional confidence**: Users should feel they're learning something important and well-built

### Aesthetic Direction
**Visual Tone**: Light, white-background design with vibrant purple (#6D28FF) as the sole accent. Clean, modern, institutional. Abstract gradient blurs add depth without noise.

**Theme**:
- White/light backgrounds (not cream, not warm paper)
- Purple (#6D28FF) for all interactive elements, CTAs, progress indicators, and emphasis
- Near-black (#050505) for primary text, muted gray-purple (#565567) for secondary
- Light gray borders (#E4E3EB) for structure
- Rounded corners throughout (pill buttons, card radii)
- Abstract purple gradient blurs as atmospheric background decoration

**Typography**: Inter (or matching geometric sans-serif) — clean, modern, highly legible at all sizes. Replaces the previous Neue Montreal + DM Sans pairing.

**References**:
- Skyeco.com (primary reference — this is the brand to match)
- Linear.app (clean, modern, institutional)
- Vercel (light, precise, professional)

**Anti-References**:
- Moleskine/notebook aesthetics (warm cream, Swiss typography, sharp corners)
- Corporate enterprise software (dense, gray, lifeless)
- Gamified or playful interfaces (badges, confetti, cartoon elements)
- Glassmorphism or heavy gradients (Web3 cliché)
- Dark mode (Skyeco.com is light; this course should match)

### Visual Accent System

**Layered background effects** (used sparingly — hero sections, key pages only):
- **Gradient base**: Multi-stop purple gradients (`#6B5CE7` → `#2D1F8A`) at 135-160° angles
- **Gradient overlay**: Animated opacity pulse (0.7–1.0) on 6s cycle
- **Gradient wave**: Secondary radial gradient with 8s opacity cycle
- **God rays**: Rotating light elements with `mix-blend-mode: screen`, 20s full rotation
- **Noise texture**: SVG `feTurbulence` filter at 3% opacity for subtle grain
- **Vignette**: Radial gradient edge darkening for depth

**Animation timing**:
- Gradient pulse: 6s ease-in-out infinite alternate
- Wave shift: 8s ease-in-out infinite alternate
- God rays rotation: 20s linear infinite
- All animations use `prefers-reduced-motion` fallback

### Design Principles

1. **White is the Canvas**: Clean white backgrounds let content breathe. No warm tints, no paper textures. The page is a screen, not a notebook.

2. **Purple is the Signal**: #6D28FF is the only accent color. It marks everything interactive — buttons, links, progress bars, active states. Nothing else competes for attention.

3. **Round the Edges**: Pill buttons, rounded cards, soft corners. Sharp Swiss corners are out; modern rounded geometry is in. The interface should feel contemporary, not archival.

4. **Depth Through Blur, Not Shadow**: Abstract purple gradient blurs create visual depth behind hero sections and key areas. No drop shadows, no elevation hierarchy — depth comes from color and light.

5. **Institutional Clarity**: Every element exists to serve the content. Typography is clean and legible. Hierarchy is established through size, weight, and color — never decoration. The course should feel like it was built by the same team as Skyeco.com.
